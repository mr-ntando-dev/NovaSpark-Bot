ℹ️ How to deploy a new Render server

1. Go to render.com → New → Web Service → connect your repo
2. Build: npm install   Start: node hosting/server.js
3. Set env vars: MAX_BOTS=10 SERVER_ID=server-X ADMIN_USER=ntando ADMIN_PASS=ntando
4. Copy the live URL and add it here using the + Add Server button above
