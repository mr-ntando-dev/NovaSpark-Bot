➕ Add Another Server on Render

Each Render service runs independently. Deploy a new one to get more bot slots. Steps below:

1. Go to render.com → New → Web Service
2. Connect your GitHub fork of NovaSpark-Bot
3. Build command: npm install
4. Start command: node hosting/server.js
5. Set these environment variables:
MAX_BOTS=10
SERVER_ID=server-2
PORT=10000
NODE_ENV=production

💡 Change SERVER_ID to server-3, server-4 etc. for each new instance. Change MAX_BOTS to any number you want (10 recommended for free tier, 50+ for paid).
